# Code of Conduct

This project follows the **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.

The full text is available at the link above.

## Summary

We want ORCH to be a welcoming, respectful, and productive space for everyone — contributors, maintainers, and users alike. In practice, this means:

- Be kind and patient in issues, PRs, and discussions.
- Assume good faith. Prefer questions over accusations.
- Critique code and ideas, not people.
- Help newcomers. Everyone was new once.

## Scope

This Code of Conduct applies to all project spaces — the repository, issues, pull requests, discussions, and any community channels maintained under the ORCH name.

## Reporting

If you witness or experience behavior that violates this Code of Conduct, please report it privately via the GitHub [Security tab](https://github.com/oxgeneral/ORCH/security) → **Report a vulnerability** (it's the same private channel, reused for conduct issues), or open a private discussion with the maintainer.

Reports will be handled confidentially. The maintainer may warn, temporarily restrict, or permanently remove anyone whose behavior is incompatible with this Code of Conduct.
