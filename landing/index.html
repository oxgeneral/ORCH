new

State machine

Tasks flow through todo → in_progress → review → done. Every transition validated. No task gets lost.

06

Safe parallel execution

Run multiple agents with scope isolation — each agent gets its own git worktree. File conflicts detected before they happen.

07

Auto merge-back

When an agent finishes in a worktree, changes are automatically merged back to the main branch. No manual git juggling.

08

Rework loop

Reject a task with feedback — the agent retries with your notes as context. Iterate until it's right.

TUI dashboard

Full-screen React/Ink terminal UI. Live tasks, agent activity feed, token tracking — keyboard-driven.

10

Smart retries

Exponential backoff for failures. Stall detection kills zombies. Your tasks finish even when individual runs fail.

11

Shared context

Agents publish context that other agents can read. LiquidJS templates inject project info, scope, and retry history into prompts.

Zero infrastructure

No cloud. No database. All state in .orchestry/ — YAML configs, JSON state, JSONL logs. Git clone and run.

Agent Teams

Move beyond isolated agents. Create coordinated teams where agents communicate, share discoveries, and delegate subtasks — just like a real engineering team.

  • Teams with leads — assign a lead agent who coordinates the team's work
  • Direct messaging — agents send messages to specific teammates
  • Broadcasts — announce to all agents or team-scoped groups
  • Mailbox delivery — messages injected into prompts at task dispatch
  • Shared context store — key-value pairs readable by all agents
  • Task pools — teams claim and distribute work automatically
Agent Teams CLI
$ orch team create platform --lead architect
✓ Created team "platform" → team_k2m

$ orch team join team_k2m backend
✓ Agent backend joined team platform

$ orch msg send backend "Use PostgreSQL for the new schema" -s "DB decision"
✓ Message sent → backend

$ orch msg broadcast "API v2 spec is ready" --team team_k2m
✓ Broadcast sent to 3 agent(s)

$ orch context set db_schema "users(id,email,role)"
→ Shared with all agents

Install & run

02

Create tasks
