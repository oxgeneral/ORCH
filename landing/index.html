CLI-first agent orchestration

Coordinate AI agents from your terminal

A lightweight CLI orchestrator for managing teams of AI agents. Parallel execution. State machine task flow. Zero cloud dependencies.

Get Started Learn more
v1.0 — open source
$ orch init
→ Created .orch/ config
 
$ orch agent add backend --adapter claude --role "Senior Developer"
→ Agent backend registered
 
$ orch task add "Implement auth module" -p 1 --assignee backend
→ Task TSK-001 created
 
$ orch run --all --watch
● Running — 3 agents active, 5 tasks dispatched

Built for
precision

06 features
01

State machine

Tasks flow through todo → in_progress → review → done. No shortcuts. No chaos.

02

Parallel runs

Execute multiple agents simultaneously with automatic task dispatch and load balancing.

03

Smart retries

Exponential backoff for failed tasks. Configurable max attempts. Agents don't give up.

04

TUI dashboard

Full-screen interactive terminal UI built with React/Ink for real-time monitoring.

05

Workspace isolation

Shared, worktree, or fully isolated modes. Agents don't step on each other.

06

Zero dependencies

No cloud. No database. Pure file-based storage. Install and run in seconds.

Three steps

01

Define agents

Register AI agents with roles, adapters, and capabilities.

02

Create tasks

Add tasks with priorities, descriptions, and assignments.

03

Run & watch

Launch the orchestrator. Monitor progress in the TUI.
