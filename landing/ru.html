Возможности

Создан для точности
и контроля

Всё, что нужно для управления командой AI-агентов прямо из терминала

Конечный автомат

Задачи проходят цепочку todo → in_progress → review → done. Без хаоса и пропусков.

Параллельный запуск

Запускайте нескольких агентов одновременно с автоматическим распределением задач.

Умные повторы

Экспоненциальный backoff для упавших задач. Настраиваемое число попыток. Агенты не сдаются.

TUI дашборд

Полноэкранный интерактивный интерфейс в терминале на React/Ink для мониторинга в реальном времени.

Изоляция воркспейсов

Shared, worktree или полная изоляция. Агенты не мешают друг другу.

Без зависимостей

Без облака. Без базы данных. Чистое файловое хранилище. Установка и запуск за секунды.
